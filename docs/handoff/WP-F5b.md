## Fehlende Backend-Routen / Befunde (nicht erfunden)
- **Quarantäne nicht zählbar:** keine Route zählt dauerhaft fehlgeschlagene Verarbeitung (kein `status=quarantine`, kein Zähler an `…/documents`). Die Karte zeigt „In Verarbeitung“ (enthält Quarantäne) und sagt das im Text; „Warteschlange/fehlgeschlagen“ wie gewünscht braucht eine Route (z. B. Zähler je `phase` oder Filter `ingest_state=failed_permanent`).
- **Konsumordner nicht testbar** (Backend 409 `test_not_supported`, Ordner nur im Worker): die UI bietet den Test nur für Mail an; das Ergebnis eines Ordnerlaufs steht nach „Jetzt ausführen“ in `last_status`/`last_error`. Der Konsumordner-Wurzelpfad (`DMS_FOLDER_ROOT`) wird nicht ausgeliefert; die Seite zeigt `<Konsumordner>/<Mandant>/<Pfad>`.
- **`run` antwortet 202 ohne Ergebnis:** die UI zeigt „eingeplant“, das Ergebnis erscheint erst nach „Aktualisieren“ (kein Polling, kein Ereignis; K7).
- **Host-Allowlist nicht von anderen 422 unterscheidbar:** `config.host` kommt mit Code `invalid` für ungültigen und nicht erlaubten Host; die Meldung nennt beides.
- Token: nicht an einen Mandanten gebunden, keine Rotation, kein Nutzungsprotokoll (D4); `last_used_at` höchstens minütlich genau.
